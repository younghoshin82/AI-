현재 폴더에 아래 내용으로 `PRD.md`와 `CLAUDE.md` 파일 2개를 생성(Create/Write)해줘

[PRD.md 내용]
- 목적: AI 기반 투자계획서 검증 및 검토 요약
- 주요기능: 투자자료 업로드, PDF/Excel 정보 추출, 투자비 검증, 경제성 검증, 기대효과 검증, 리스크 도출, 투자검토요약 생성
- 사용자: 투자기획 담당자

[CLAUDE.md 내용]
역할: 투자기획팀 심사 담당자
1. 주요 정보 추출
2. 자료 간 수치 일치 여부 검증
3. 경제성 가정 검토
4. 기대효과 중복 가능성 검토
5. 리스크 식별
6. 투자검토요약 작성
원칙:
- 자료에 없는 수치는 추정하지 않는다.
- AI의 의견과 사실을 구분한다.
- 투자 승인/부결을 판단하지 않는다.
- 모든 결과에 근거를 표시한다.
검증 등급: 높음 / 주의 / 확인필요 / 정상

==========================================

PRD.md와 CLAUDE.md를 읽고 다음 항목을 정리한 `DESIGN.md` 문서를 생성해줘. 코딩은 아직 시작하지 마
1. 요구사항 및 사용자 업무 흐름 분석
2. Streamlit 기반 시스템 및 멀티페이지 화면 설계
3. 폴더 구조 및 개발 로드맵

==========================================

Streamlit으로 UI 뼈대를 구현해줘
1. Sidebar에 5개 메뉴 구성: [1. 대시보드, 2. 투자건 등록, 3. 정보추출 결과, 4. AI 검증 결과, 5. 투자검토 요약]
2. `AI_Investment_Validation_Sample_Pack` 폴더 내의 Project_01 ~ Project_05 데이터를 읽어서 사이드바 또는 대시보드에서 프로젝트를 선택할 수 있게 연동해줘
3. 선택된 프로젝트의 PDF, Excel 파일명 목록이 화면에 표시되도록 더미 데이터 포함 뼈대를 만들어줘

==========================================

선택된 프로젝트의 PDF 및 Excel 파일에서 다음 필수 항목을 추출하는 파서(Parser) 및 화면 표시 기능을 구현해줘
- 추출 항목: 투자명, 총 투자비, NPV, IRR, WACC, 회수기간, 기대효과
- 추출 결과는 '3. 정보추출 결과' 화면에 표 형태로 표시하고, 출처 파일명과 시트/페이지 정보도 함께 명시해줘

==========================================

'4. AI 검증 결과' 메뉴에 적용할 검증 룰 엔진(Rule Engine)을 구현해줘

1. 투자비 검증: (투자계획서 총투자비 == 투자비 내역 합계) 검증. 불일치 시 등급 '높음' 부여
2. 경제성 검증: WACC, NPV, IRR, 회수기간 지표 존재 여부 검증. 누락 시 등급 '확인필요' 부여
3. 기대효과 검증: (세부효과 합계 == 투자계획서 기재 효과) 검증. 불일치 시 등급 '높음' 부여
4. 결과는 등급별 색상 배지(높음: 빨강, 확인필요: 주황, 정상: 초록 등)로 시각화해줘

==========================================

'5. 투자검토 요약' 메뉴에 LLM 기반 분석 및 요약 리포트 생성 기능을 구현해줘

1. 리스크, 추가확인사항, 현업 질문사항, 투자검토 코멘트를 생성 (CLAUDE.md 원칙 준수: AI 의견임을 명확히 표시)
2. 다음 항목으로 구성된 마크다운 방식의 최종 '투자검토요약 초안'을 생성하고 PDF/텍스트로 다운로드할 수 있는 버튼을 추가해줘
   - 1. 투자개요 / 2. 투자비 검토 / 3. 경제성 검토 / 4. 기대효과 검토 / 5. 주요 리스크 / 6. 현업 추가 확인사항 / 7. 종합 의견


==========================================

(제미나이 확인 후 프롬프트 작성)

UI 화면 상에 어색하게 표시되거나 영어로 렌더링되는 용어들을 깔끔한 한글로 수정해줘.

1. 검증 등급 및 상태 배지 텍스트 한글화:
   - Error / 엘리 / 키움 퍼즐 -> '높음' (빨간색)
   - Warning / 주의 -> '주의' (주황색)
   - Check / 필요 확인 -> '확인필요' (노란색/주황색)
   - OK / 정상 / 구성 / 돋보 -> '정상' (초록색)

2. 파일 유형 표시 한글화:
   - Excel / 뛰어나다 -> '엑셀 (Excel)'
   - PDF -> 'PDF'
   - Word -> '워드 (Word)'

3. 5. 투자검토요약 메뉴의 목차 섹션 제목 한글화:
   - 1. 투자개요
   - 2. 투자비 검토
   - 3. 경제성 검토 (관리자로 표기되지 않도록 수정)
   - 4. 기대효과 검토
   - 5. 주요 리스크 [AI 의견]
   - 6. 현업 추가 확인사항 [AI 의견]
   - 7. 종합 의견 [AI 의견] (잠시 기다려요로 표기되지 않도록 수정)

모든 페이지의 라벨과 설명 문구가 자연스러운 한국어로 출력되도록 app.py 및 관련 컴포넌트 코드를 정돈해줘.
